## ADDED Requirements

### Requirement: All 21 counties with state codes

`shared/nj` SHALL list all 21 New Jersey counties in alphabetical order, each with its 2-digit state code: Atlantic 01, Bergen 02, Burlington 03, Camden 04, Cape May 05, Cumberland 06, Essex 07, Gloucester 08, Hudson 09, Hunterdon 10, Mercer 11, Middlesex 12, Monmouth 13, Morris 14, Ocean 15, Passaic 16, Salem 17, Somerset 18, Sussex 19, Union 20, Warren 21. `NJCounty` SHALL be the type of any of the 21. A county's code SHALL come from this mapping and SHALL NOT be computed from its position in any list.

#### Scenario: Ocean's code

- **WHEN** the code for Ocean is looked up
- **THEN** it is `15`

#### Scenario: Counties civilview doesn't serve

- **WHEN** `NJ_COUNTIES` is listed
- **THEN** it has 21 entries and includes Mercer, Somerset, Sussex and Warren

### Requirement: Municipality code map

`shared/nj` SHALL export a static, checked-in map of all 564 NJ municipalities. Each entry SHALL have:

- its 4-digit code;
- its county;
- its njparcels display name;
- a kind (township, borough, city, town, village, or none);
- a base name: lowercase, with punctuation and the kind suffix removed.

Every code SHALL be unique. Each code's first two digits SHALL equal its county's state code.

#### Scenario: Renamed municipality keeps its code

- **WHEN** the entry for code `0717` is read
- **THEN** its county is Essex and its name is "City Of Orange Twp"

#### Scenario: Consolidated municipality

- **WHEN** the Mercer entries are listed
- **THEN** Princeton has code `1114`, and no entry has code `1109` or `1110`

#### Scenario: Map shape

- **WHEN** the map test runs
- **THEN** it finds 21 counties and 564 entries with unique codes, each prefixed by its county's code

### Requirement: Map is regenerated by script

A checked-in script SHALL rebuild the municipality map from the njparcels home page in one request. It SHALL fail without writing the file when the parsed page doesn't yield 21 counties.

#### Scenario: Regeneration

- **WHEN** the script runs against the current home page
- **THEN** it rewrites the map file, and the map test passes

#### Scenario: Page layout changed

- **WHEN** the home page yields fewer than 21 counties
- **THEN** the script exits non-zero and the map file is unchanged

### Requirement: Postal-place aliases

`shared/nj` SHALL hold a hand-kept table, per county, from a mailing-city name to the code of the one municipality it lies in. A place that spans more than one municipality SHALL NOT be in the table.

#### Scenario: Williamstown

- **WHEN** a Gloucester listing's city is "Williamstown"
- **THEN** the alias table gives Monroe Twp's code

#### Scenario: Place spanning two municipalities

- **WHEN** a Camden listing's city is "Sicklerville"
- **THEN** the alias table has no entry for it

### Requirement: Resolving a listing's municipality

`resolveMunicipality` SHALL return a municipality code and its source (`notice`, `city` or `alias`), or null. It SHALL consider only municipalities in the listing's county, and SHALL try, in order:

1. **Notice:** the first "(Township|Borough|City|Town|Village) of `<Name>`" or "Municipality: `<Name>`" in `parcel`, then in `description`. A match by base name with more than one candidate SHALL be narrowed to the candidate whose kind matches the word before "of".
2. **City:** the listing's `city`, then any parenthetical inside it, matched by base name to exactly one municipality.
3. **Alias:** the alias table.

Matching SHALL be exact on base name. Any step that leaves zero or several candidates SHALL fall through to the next. When no step yields a single code, the result SHALL be null.

#### Scenario: Notice text wins over mailing city

- **WHEN** a Monmouth listing's city is "Freehold" and its description says "situated in the Township of Freehold"
- **THEN** the result is Freehold Twp's code with source `notice`

#### Scenario: Kind disambiguates

- **WHEN** an Atlantic listing's description says "City of Egg Harbor"
- **THEN** the result is Egg Harbor City's code, not Egg Harbor Twp's

#### Scenario: Ambiguous city

- **WHEN** an Atlantic listing's city is "Egg Harbor" and its text names no municipality
- **THEN** the result is null

#### Scenario: Parenthetical city

- **WHEN** a Cumberland listing's city is "Bridgeton (fairfield Township)" and its text names no municipality
- **THEN** the result is Fairfield Twp's code with source `city`

#### Scenario: Other county's municipality

- **WHEN** a Bergen listing's text says "Township of Washington"
- **THEN** the result is Bergen's Washington Twp, never another county's
